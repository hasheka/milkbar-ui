# MilkBar UI — Frontend Web App

A responsive MilkBar website UI designed to provide a clean, modern, and user-friendly experience for exploring milkshake products and brand information.

## Project Overview

MilkBar UI is a frontend web application developed to practice responsive web design and create an interactive user interface using core web technologies.

## Features

- Modern landing page design
- Responsive layout for different screen sizes
- Product showcase section
- Interactive navigation
- Clean UI components and styling

## Tech Stack

| Layer | Technology |
|------|------------|
| Structure | HTML5 |
| Styling | CSS3 |
| Logic | JavaScript |
| Design | Figma |
